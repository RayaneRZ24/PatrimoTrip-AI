# État du pilote — 3 novembre 2026

## Acquis et contrôlés

- Trois fiches de monuments de Marrakech, toutes rattachées au Maroc dans les déclarations Wikidata.
- Trois photographies Commons originales, chacune vérifiée par taille, SHA1 source et SHA256 local.
- Licences photographiques : Koutoubia CC BY-SA 4.0 ; Bahia CC BY-SA 4.0 ; Ben Youssef CC BY-SA 2.5.
- Inspection visuelle des trois images : cohérence avec les métadonnées, avec limites précisées dans `sites.json` et `ATTRIBUTIONS.md`.
- Sources brutes et révisions conservées. Coordonnées déclarées à proximité les unes des autres dans Marrakech, non vérifiées sur le terrain.
- Collecteur de textes français, vérification de l'identité de l'article, de la licence et des révisions, cache sans remplacement silencieux, rapport d'acquisition et tests de refus des données invalides.

## Bloqué dans l'environnement cloud

L'acquisition réelle des trois articles via `fr.wikipedia.org` reçoit une erreur de connexion du proxy HTTP 403. Aucun article n'a été acquis ni examiné historiquement dans cette phase. Le domaine est présent dans le brouillon de configuration réseau ; la sauvegarde du brouillon n'active pas à elle seule les accès de la machine courante. Les ajouts `data.gov.ma` et `whc.unesco.org` sont aussi préparés pour approfondir les sources officielles.

Le collecteur peut être exécuté sur le PC de l'utilisateur ou repris dans le cloud une fois les accès appliqués. Les tests ne remplacent pas cette collecte réelle. Un rapport signalant zéro instantané n'est pas un corpus historique prêt.

## Conditions avant activation dans l'application

Acquérir et relire les textes, contrôler les faits et les rôles historiques, compléter autant que possible avec une autre source, puis préparer les passages RAG. Constituer ensuite des références visuelles et une évaluation distincte. Les seuils actuellement mesurés pour Paris ne sont pas automatiquement valides à Marrakech.

Les horaires, tarifs et accès restent inconnus. Les trois photos ne permettent pas de mesurer la précision d'un système de reconnaissance. L'application et les données parisiennes n'ont pas été modifiées.
